# Skills vendored from mattpocock/skills

These 27 skills are copied from https://github.com/mattpocock/skills
(commit 4ae2317ddb22b046e26455e4f9c9b3aaaf62212d, plugin version 1.3.2):
the same set the official `mattpocock-skills` Claude Code plugin ships.
Codex-only `agents/openai.yaml` files were left out. MIT licence: see
`LICENSE-mattpocock-skills`.

Claude Code loads them automatically from `.claude/skills/`. Run
`/setup-matt-pocock-skills` once to configure the issue tracker, triage
labels and docs location for this repo.

To update, re-copy the folders from a newer commit of the upstream repo.
