# Labels de tri

Les skills parlent de cinq rôles de tri canoniques. Ce fichier fait correspondre ces rôles aux labels réellement utilisés dans le suivi des tickets de ce dépôt.

| Label dans mattpocock/skills | Label dans notre suivi | Signification                                      |
| ---------------------------- | ---------------------- | -------------------------------------------------- |
| `needs-triage`               | `needs-triage`         | Le mainteneur doit évaluer ce ticket               |
| `needs-info`                 | `needs-info`           | En attente d'informations de la part de l'auteur   |
| `ready-for-agent`            | `ready-for-agent`      | Entièrement spécifié, prêt pour un agent autonome  |
| `ready-for-human`            | `ready-for-human`      | Doit être réalisé par un humain                    |
| `wontfix`                    | `wontfix`              | Ne sera pas traité                                 |

Quand une skill mentionne un rôle (par exemple « appliquer le label de tri prêt pour un agent »), utiliser le label correspondant de ce tableau.

Modifier la colonne « Label dans notre suivi » pour l'aligner sur le vocabulaire réellement utilisé.
